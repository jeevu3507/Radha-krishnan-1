# Code of Conduct

We follow a simple, mission-first code of conduct.

## Our pledge

We are building a platform that touches the careers of more than four lakh
teachers across Tamil Nadu. We pledge to make participation in this project
a respectful, harassment-free experience for everyone, regardless of age,
gender, language preference, disability, caste, religion, region, or seniority.

## Expected behaviour

- Treat colleagues with respect, both in code review and meetings.
- Critique code and designs, not people.
- Assume good intent; verify before escalating.
- Use English **or** Tamil as you prefer; technical artifacts are bilingual
  where they reach end users.
- Credit ideas and acknowledge contributions.

## Unacceptable behaviour

- Personal attacks, harassment, derogatory remarks.
- Discriminatory or sexualised language.
- Sharing private information of teachers, applicants, or colleagues outside
  authorised channels.
- Sustained disruption of reviews, standups, or other forums.

## Enforcement

Report concerns to `tnemis-architecture@tnschools.gov.in` or the Programme
Office. Reports are reviewed confidentially. Outcomes range from a private
conversation to removal from the project.

## Scope

Applies to all project spaces — code review, issues, PRs, chat, meetings,
and any public representation of the project.
